# Jupyter Notebooks

This directory contains interactive Jupyter notebooks for learning and experimenting with the Biomedical Knowledge Lookup library.

## Notebooks

### Getting Started
- **01-getting-started.ipynb** - Basic usage, installation, and quick start examples

### Advanced Topics
- **02-api-keys.ipynb** - API key configuration for sources requiring authentication
- **03-rate-limiting.ipynb** - Rate limiting strategies and performance optimization
- **04-error-handling.ipynb** - Error handling patterns and best practices

## Installation

Install Jupyter and the required dependencies:

```bash
pip install jupyter
pip install -e .
```

## Running the Notebooks

```bash
# Start Jupyter
jupyter notebook

# Or use JupyterLab
jupyter lab
```

Then navigate to the `docs/examples/notebooks/` directory and open any notebook.

## Prerequisites

- Python 3.10+
- Jupyter Notebook or JupyterLab
- Biomedical Knowledge Lookup installed
